# TODO 앱

의존성 없이 HTML/CSS/JavaScript만으로 만든 할 일 관리 앱입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 빌드나 설치가 필요 없습니다.

## 기능

- 할 일 추가 (Enter 또는 "추가" 버튼)
- 완료 체크 / 전체 완료·해제 (입력창 왼쪽 ✓ 버튼)
- 수정: 항목을 더블클릭하거나 ✎ 버튼 → Enter로 저장, Esc로 취소 (내용을 비우면 삭제)
- 삭제: ✕ 버튼, "완료 항목 삭제"로 완료된 항목 일괄 삭제
- 필터: 전체 / 진행 중 / 완료 (URL 해시 `#/active`, `#/completed`로 유지)
- `localStorage`에 자동 저장, 여러 탭 간 동기화
- 다크 모드 자동 대응, 모바일 화면 대응

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 마크업 |
| `style.css` | 스타일 (라이트/다크 테마) |
| `app.js` | 상태 관리, 렌더링, 이벤트 처리 |
